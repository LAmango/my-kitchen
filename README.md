# My Kitchen — Gluten-Free Chicken Pot Pie

A small React + Vite recipe site with a clean, high-contrast editorial layout. Ingredient amounts are repeated in each cooking step, so the instructions work without jumping back to the ingredient list.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

The included workflow builds and deploys on every push to `main` and supports manual runs. In the repository's **Settings → Pages**, set the build and deployment source to **GitHub Actions**. The configured Vite base path is `/my-kitchen/`.

Expected site address: <https://lamango.github.io/my-kitchen/>

Check package labels, especially the crust, flour blend, and broth, to confirm they are gluten-free.
